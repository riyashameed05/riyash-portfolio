# Riyas Hameed — Portfolio

Modern responsive portfolio built with Angular 20 and CSS.

## Stack

- Angular 20 standalone components
- TypeScript
- Angular animations
- Custom responsive CSS
- Zoneless change detection

## Local development

```bash
npm install
npm start
```

Open the local URL shown by Angular CLI.

## Production build

```bash
npm run build
```

The production output is generated in `dist/riyas-portfolio`.

## Vercel

Import this GitHub repository into Vercel and set the framework to Angular if it is not detected automatically. Every push to `main` can trigger a new deployment when Git integration is enabled.

Build command: `npm run build`

Output directory: `dist/riyas-portfolio/browser`
